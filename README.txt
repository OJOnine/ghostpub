귀신주막 · GitHub Pages 업로드용

지금 초대장의 이미지 수정, 속도 최적화, 지도 연결, 운세 12종을 포함합니다.
HTML 안에 그림·글꼴·버튼 기능을 담았습니다. 이 파일을 만든 것만으로 웹사이트가 공개되지는 않습니다.

1. ZIP 압축을 풀어 주세요. ZIP 파일 자체를 올리는 방식이 아닙니다.
2. GitHub에서 사용할 저장소를 정한 뒤, 압축을 푼 파일들을 저장소 맨 위에 올립니다.
3. Settings → Pages에서 main 브랜치와 /(root)를 배포 원본으로 선택합니다.
4. GitHub가 표시한 Pages 주소를 열어 확인합니다.
   주소 예시: https://계정명.github.io/저장소명/

공유 버튼은 현재 열린 GitHub Pages 주소를 사용합니다. ChatGPT 주소로 돌아가지 않습니다.
카카오톡 링크 미리보기 그림은 배포 주소가 정해진 후 og:image를 절대주소로 맞추고 확인해야 합니다.
예시: https://계정명.github.io/저장소명/og-cover.jpg

무료 GitHub Pages는 공개 저장소에서 사용합니다. 공개 저장소에는 올린 HTML과 그림을 다른 사람도 볼 수 있습니다.
실제 공개 여부와 저장소 선택은 직접 결정해 주세요. 이 자료에서는 GitHub 저장소 생성이나 공개 배포를 실행하지 않았습니다.
